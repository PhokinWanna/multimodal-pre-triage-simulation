# Dataset source links

The following five third-party sources were reported as inputs to the earlier
CNN research workflow. These links point to publisher or project pages; they
do not establish that every image is licensed for this project's use or
redistribution.

1. [Flickr-Faces-HQ (FFHQ) dataset on Kaggle](https://www.kaggle.com/datasets/arnaud58/flickrfaceshq-dataset-ffhq)
2. [Massive Skin Disease Balanced Dataset on Kaggle](https://www.kaggle.com/datasets/muhammadabdulsami/massive-skin-disease-balanced-dataset)
3. [Skin Problem Detection Relabel Clean 3 on Roboflow Universe](https://universe.roboflow.com/parin-kittipongdaja-vwmn3/skin-problem-detection-relabel-clean3)
4. [Skin Problem Detection Relabel Clean 2 on Roboflow Universe](https://universe.roboflow.com/parin-kittipongdaja-vwmn3/skin-problem-detection-relabel-clean-2)
5. [FairFace dataset on Kaggle](https://www.kaggle.com/datasets/alexstvn/fairface)

The applicability and provenance of some licenses remain unresolved, and the
images contain recognizable faces. Do not download, use, publish, or
redistribute images without first reviewing the source terms and obtaining
any required permissions. See [`../docs/data/README.md`](../docs/data/README.md)
for the provenance and privacy caveats currently known.
