# CNN training outputs

This directory is the default destination for new Model-02 CNN training runs.
Each run is written to a new timestamped subdirectory and contains its model,
metrics, scores, configuration, and plots.

Generated model files and evaluation outputs are not committed automatically.
Review dataset permissions, privacy, and evaluation limitations before
sharing any run artifacts.

Previously recorded Model-03 experiment artifacts are kept with their report
under [`../../scripts/train/cnn/model03/results/`](../../scripts/train/cnn/model03/results/).
