# Training scripts

Training and CNN evaluation utilities are organized under `cnn/`:

- [`cnn/SPLIT_README.md`](cnn/SPLIT_README.md) documents the patch extraction,
  prefix-grouped splitting, and Model-02 training workflow.
- [`cnn/model03/README.md`](cnn/model03/README.md) documents the controlled
  Model-03 focal-loss experiment.

Training data is local-only and excluded from version control. See the
repository [data guide](../../docs/data/README.md) before using any source
images.
