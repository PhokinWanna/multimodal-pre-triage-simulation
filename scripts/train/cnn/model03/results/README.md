# Model-03 experiment results

This folder contains the controlled focal-loss comparison, summary reports,
metrics, score files, training histories, checkpoints, and generated figures.
Use [`FINAL_SUMMARY.md`](FINAL_SUMMARY.md) as the starting point and
[`MODEL03_TECHNICAL_APPENDIX.md`](MODEL03_TECHNICAL_APPENDIX.md) for detailed
architecture and calculation information.

Results are patch-level and filename-prefix-grouped. Prefix grouping is not
verified person separation and does not establish clinical performance.
Check the dataset rights and limitations in
[`../../../../../docs/data/README.md`](../../../../../docs/data/README.md)
before reusing or redistributing data or artifacts.
