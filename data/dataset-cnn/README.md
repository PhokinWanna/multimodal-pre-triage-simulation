# CNN dataset (not included)

The skin-flushing CNN was trained on about 16,800 face images (8,135 Normal,
8,638 Flushing) combined from five public datasets. The images are **not
committed** to this repository: there are more than 32,000 files, and they
contain recognizable faces whose licenses do not all allow redistribution.

## Get the data

1. Download the source datasets from their original publishers, listed in
   [`archive/DATASET_SOURCES.md`](../../archive/DATASET_SOURCES.md).
2. Review each dataset's license before use. Provenance and license notes are
   in [`docs/data/README.md`](../../docs/data/README.md).
3. Place the images locally under `Normal/` and `Flushing/` in this folder.
   Both folders are ignored by Git.

For academic review, contact the repository owner for access details.
