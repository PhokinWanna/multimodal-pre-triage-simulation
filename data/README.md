# Local and generated data

This directory is reserved for local inputs and runtime-generated data. Do not
commit source images, extracted face patches, split datasets, recordings, or
runtime case evidence.

- `dataset-cnn/Normal/`, `dataset-cnn/Flushing/`: authorized source images.
- `dataset-cnn/patches/`: face-zone patches generated by the CNN extractor.
- `dataset-cnn/splits/`: train, validation, and test copies created by the splitter.
- `dataset-posture/`: local posture datasets (not committed).
- `runtime/evidence/`: locally captured application images.
- `runtime/spool_outbox/`: locally queued case and nurse-assistance payloads.

CNN data paths are excluded by `.gitignore`. Review source permissions and
privacy restrictions before using any dataset. See
[`../docs/data/README.md`](../docs/data/README.md).
